# Changelog

All notable changes to CueMark are documented in this file.

## [0.1.0]

### CueMark release
- Renamed the app to CueMark — bookmarking where you left off — across the application, Android package, storage, caches, backups, functions, documentation, and build tooling.
- Added a searchable Dashboard with list/grid views, category and status filters, Continue Watching, Recently Added, Completed, On Hold, Dropped, and Not Started sections, progress indicators, ratings, sorting, grouping, and quick actions.
- Added category-first Discover, Explore, source-specific search, ten metadata providers, custom metadata sources, API-key support, offline fallback, retries, refresh controls, and cached thumbnails/fonts.
- Added full detail pages for series, movies, anime, manga, novels, and games with seasons, episodes, synopsis, ratings, notes, progress tracking, next-episode actions, artwork, screenshots, and provider metadata.
- Added encrypted Android storage, encrypted backups, folder-tree sync, TAR/JSON/SQDBE import/export, cloud/WebDAV sync, scheduled backups, recovery previews, cache/storage management, and safe restore controls.
- Added CSV, TSV, TXT, JSON, and TAR import/export workflows with previews, duplicate handling, category mapping, metadata queues, retries, pause/resume, and status tracking.
- Refreshed Settings with themes, fonts, accessibility presets, reduced motion, text size, colors, dashboard controls, navigation management, metadata/storage, notifications, security, privacy/network, data maintenance, and About pages.
- Added App Lock with PIN, pattern, password, recovery questions, biometric/device credentials, auto-lock, sensitive-note protection, and Android notification/share/widget integrations.
- Improved Timeline and Statistics with watch history, genres, networks, ratings, time spent, episode activity, marathons, progress estimates, and responsive charts.
- Added draggable mobile navigation/source ordering, customizable bottom-bar icons, direct page navigation, route/query preservation, swipe-back, popup-first Android Back handling, pull-to-refresh, loading skeletons, toasts, and reduced-motion support.
- Improved responsive UI, themes, contrast, modal surfaces, cards, episode checkboxes, rating controls, artwork-color backgrounds, accessibility, and edge-to-edge mobile layouts.
- Removed obsolete settings pages and legacy icon resources; reorganized the web structure, updated documentation, and added build requirements and performance guidance.
