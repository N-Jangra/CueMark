Usage Guide

How to use each tab and setting.

Jump to a section

Dashboard

Your tracked titles, grouped by category (TV Series, Movies, Anime, Manga, Games, etc — whichever you've enabled in Settings → Tracking Choices). Switch between a list view and a poster grid in Settings → Dashboard & Navigation. Tap a card to open its detail page; use the search bar and status filter to narrow a long list.

Discover

Pick a category chip, then search — results merge across every enabled metadata source for that category. Tap the filter (sliders) icon next to the search bar to limit a search to specific sources only; that choice is saved per category. Tapping a result opens its detail page; nothing is saved to your list until you change something there.

Sources & Explore

Sources lists every built-in metadata source, so you can search just one directly. Explore is a shortcut hub: only your currently enabled sources, plus quick links to Timeline and Statistics, and a toolbox icon to Settings → Metadata Sources to enable more.

Show/Movie Detail Page

Shows poster, summary, and metadata at the top. The Tracking group lets you set which list it belongs to, its status, and a completion date. Series/anime/dramas get a season picker and episode list — tapping an episode's checkmark marks it (and everything before it) watched, which also updates status automatically. Rating and Notes sections are always available. A delete option appears in the topbar only while a title is still in Watchlist or In Progress.

Timeline & Statistics

Timeline shows a chronological feed of completions and episode-watch activity. Statistics summarizes genres, networks, ratings, and time spent watching, including a weekly chart and your biggest single-day marathons.

Settings

Every group and page in Settings, in order, with what each one does.

Appearance

  • Accessibility — adjust contrast, reduced motion, and text size individually or with an accessibility preset.
  • Theme, Main Color, and Font — change the app's palette, accent color, and typeface. Online fonts are cached after first download.
  • Animation Speed — control how quickly transitions and animations play.
  • Bottom Bar Active Style — show a selected box or color the active icon.
  • Bottom Bar Background and Transparency — choose a solid/translucent surface and adjust its opacity.
  • Show Scrollbars — display scrollbars throughout the app; they are hidden by default.

Dashboard & Navigation

  • Dashboard display — choose the view, density, grouping, sorting, category, thumbnail, rating, and progress options.
  • Dashboard actions — configure row actions, one-handed/tablet layout, rating format, and reset dashboard preferences.
  • Bottom Bar Layout — drag to reorder tabs and choose any number of optional tabs. Dashboard and Settings always remain available.
  • Bottom Menu Icons — customize the icon used by each tab.

Tracking

  • Tracking Choices — turn categories on or off, or add custom categories.
  • Category Order — drag to reorder enabled categories across the app.
  • Tracking behavior — configure automatic completion, default status, progress increments, rating reminders, and notes templates.

Language & Dates

  • Language — choose the app language.
  • Date Format — choose how dates are displayed throughout the app.

Metadata

  • Metadata mode and thumbnails — control online lookups and artwork fetching.
  • Metadata Sources — enable, reorder, configure API keys, or create custom lookup sources used by Discover and Explore.
  • Metadata refresh and sync — configure refresh intervals, retries, offline fallback, workers, and thumbnail cleanup/quality/size.

Metadata & Storage

  • Manage cached metadata, thumbnails, storage limits, and cleanup behavior from this page.

Backup & Sync

  • Folder Sync Delay — how long to wait after a change before syncing to your chosen backup folder.
  • Backups & Restore — export your data as a file, restore from a backup, or sync to a folder as a mirrored file tree.

Security

  • App Lock — require a password, configure auto-lock and background locking, use biometric fallback, and hide sensitive notes.

Privacy & Network

  • Privacy controls — manage external links, anonymous analytics, diagnostic log sharing, and Wi-Fi-only metadata.
  • Network Timeout — set how long requests may wait.
  • API Rate-Limit Delay — set the pause between API requests.

Notifications

  • Configure notification types, grouping, reminder times, quiet behavior, and snooze options.

Data

  • Configure duplicate detection, orphaned metadata cleanup, import history, selected-item exports, and database health checks.
